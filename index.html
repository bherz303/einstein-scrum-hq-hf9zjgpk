SCRUM Certification System

A live scoring, tracking, and training system for the 5 CTXH branch Monday boards — turns board hygiene from a gut call into a graded, trend-tracked, coachable standard. Covers the 12-criterion rubric, a manager-facing reference sheet, a live performance dashboard with full scorecard detail per read, and a hands-on training board with automations that mirror the real branch boards. "Done" looks like: every CTXH manager can self-check their board against a public rubric, Brian can grade any branch in minutes with a defensible score, and new managers certify on a mock board before ever touching a live one.

Rubric ruling: auto-generated damage claim pulses are exempt from No Duplicates. A pulse titled “Determine Mover Responsible” with a Project column of “New Damage Claim” is created by the board system, not by a manager, and it routinely fires several identical copies of the same claim. The bug. v1.5 changed Definition of Done to a movement-derived population — grade only what moved into Done since the previous read — to stop bulk cleanup sweeps being graded on a live board. But the mock training board's planted C10 error is "3 of the 4 Done items have no completion note," and those items are dated July by design. The fix (Brian's option B). A mock certification read grades the Done group as planted — all items, any date, damage claims still excluded. The movement window applies only to live weekly reads, which is what it was built for. Max stays 60, nothing is exempted, and all twelve criteria stay testable.
